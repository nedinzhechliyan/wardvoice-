# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/572b1f05-93a0-492d-8fa3-5afe9dec2248

## Run Locally

**Prerequisites:** Node.js (v18+ or v20+)

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy to AWS Serverless

Deploy to AWS Lambda with Function URL, DynamoDB on-demand, Amazon Bedrock, and Amazon Translate:
`npm run deploy`
